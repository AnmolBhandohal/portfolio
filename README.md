# Anmol Bhandohal — Portfolio

Datasheet/engineering-spec-styled portfolio, built with Next.js, TypeScript, and Tailwind CSS. GSAP + ScrollTrigger drive the copper signal-rail animation and section reveals; Lenis provides smooth scrolling site-wide.

Live: https://portfolio-seven-dusky-a5t6wnc1rn.vercel.app

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Deployment

Pushes to `main` auto-deploy to Vercel.
